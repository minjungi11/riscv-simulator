# 자체 테스트

프로젝트 최상위 폴더에서 `python tests/run_tests.py`로 15개 사례를 실행한다. Python 실행 명령이 `python3`인 환경에서는 `python3 tests/run_tests.py`를 사용한다. 각 사례는 독립된 임시 작업 디렉터리에서 실행한다. 정상 종료 사례는 기존 `data.out`에 1,051바이트를 먼저 채워 두고, 종료 코드와 표준 출력 전체, 새 파일의 길이와 내용 전체를 확인한다.

`fixtures/` 아래 각 폴더에는 `text.bin`과 `data.bin`이 있다. 정상 종료 사례에는 `expected_stdout.txt`와 `expected_data.out`도 있다. 기대 메모리는 아래 계산에 따라 입력 데이터에 쓸 워드를 반영하고 1,024바이트까지 0으로 채운 값이다. `generate_cases.py`로 같은 파일을 재생성할 수 있다. 이 스크립트는 명령어 필드를 조립하고 미리 정한 기대값을 파일로 저장한다. 시뮬레이터를 불러오거나 실행하지 않는다.

## 결과 도출

| 사례 | 계산과 판정 기준 | 종료 PC |
|---|---|---|
| `alu_and_x0` | x2는 `80000000`, x3은 여기에서 1을 뺀 `7fffffff`다. x2+x2의 하위 32비트는 0이고 x3−x2는 `ffffffff`다. −2048과 2047은 각각 `fffff800`과 `000007ff`다. ANDI, ORI, AND, OR의 결과는 차례로 `fffff800`, `ffffffff`, `7fffffff`, `fffff800`이다. x0를 ADDI·LW·LUI·SUB로 쓰려고 한 직후와 초기화 이후 쓰지 않은 x31의 값을 각각 저장하면 모두 0이다. | `0x00040078` |
| `branch_paths` | x2는 −2에서 시작해 −1, 0, 1로 증가한다. BLT 역분기 루프가 총 세 번 실행되어 x4는 6이다. 1 ≥ 1은 참, −1 ≥ 1과 1 < −1은 거짓이다. BEQ와 BNE는 같은 값과 서로 다른 값을 모두 비교한다. 도달한 SW들이 차례로 6, −1, 1, 1, 6을 기록한다. | `0x00040058` |
| `full_segments` | 두 입력 모두 1,024바이트다. 최초 데이터는 00부터 ff까지 네 번 반복한다. `data_base+2048−2048`과 `data_base+1020`에서 워드를 서로 바꾸면 첫 네 바이트는 `fc fd fe ff`, 끝 네 바이트는 `00 01 02 03`이다. 나머지는 입력 원본과 같다. PC `0x0004001c`에서 +992바이트 분기하면 text의 마지막 워드에 도달한다. | `0x000403fc` |
| `partial_word` | 앞의 `78 56 34 12`는 `0x12345678`이다. 1을 더해 오프셋 8에 저장하면 `79 56 34 12`가 된다. 6바이트 입력에서 오프셋 4의 워드는 `ab ef 00 00`이며 이를 오프셋 12에 복사한다. `0xfeedface` 뒤의 SW가 실행되면 첫 워드가 바뀌므로 이를 검출한다. | `0x00040018` |
| `invalid_at_entry` | text는 0 한 워드, data는 비어 있다. 첫 인출에서 종료되고 전체 덤프는 0이다. | `0x00040000` |
| `invalid_*`의 나머지 8개 | MUL, 예약된 OR funct7, XOR, SLLI, LB, SB, BLTU, AUIPC를 각각 네 번째 명령 위치에 둔다. 앞선 SW가 저장한 73은 `49 00 00 00`이다. 다섯 번째 명령도 SW이므로 조기 종료를 놓치면 종료 PC 또는 덤프가 기대값과 달라진다. 표준 출력의 명령어 값은 각 바이너리에 넣은 해당 워드다. | `0x0004000c` |
| `limit_exact` | 두 준비 명령이 카운터를 `122 × 4096 + 287 = 499999`로 만든다. 감소와 BNE가 매번 한 번씩 실행되어 총 `2 + 2 × 499999 = 1000000`개가 된다. 그다음 0을 인출하므로 정상 종료한다. | `0x00040010` |
| `limit_exceeded` | 같은 루프 뒤에 ADDI를 한 개 더 둔다. 다음 인출이 지원 명령이므로 비정상 종료 코드를 기대한다. 비정상 종료 시 파일이나 진단 문구의 형식은 비교하지 않는다. | 비정상 종료 |
